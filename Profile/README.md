# Naresh Chandra Pandey | Resume

A responsive, static resume profile built with plain HTML, CSS, and JavaScript. No installation or build step is required.

## Preview

Open `index.html` in a browser. The **Print resume** button opens the browser print dialog, where the page can also be saved as a PDF.

## Profile and credentials

The contact section links to the supplied LinkedIn profile. The Certifications section links to the corresponding Google Cloud Credly badges and Microsoft Learn achievement.

# Naresh Chandra Pandey | Portfolio

A responsive, static engineering portfolio built with semantic HTML, CSS, and vanilla JavaScript. It has no dependencies or build step.

## Preview

Open `index.html` in a browser. The page includes an engineering impact dashboard, illustrative architecture diagrams, experience timeline, case studies, technical skills, verified credentials, and contact information.

## Interactions

- Use **Ctrl+K** (or **Cmd+K** on macOS) to search the command palette and jump to a section.
- Use **Print / Save PDF** to open the browser print dialog and save a printable portfolio as a PDF.
- Scroll-triggered reveals and terminal cursor animation respect the system reduced-motion preference.

The LinkedIn profile and certification cards link to the supplied profiles. No GitHub profile URL or separate resume file was provided, so the page uses the browser's print-to-PDF flow instead of inventing either link.
